PAGE-SIZE WORKLOADS

This archive contains 32 snapshots of the same simulated machine.
Each workloads/day_XX/loads file describes one day.
Each file has 128 positive decimal integers, one per line, with no header.
Each integer is one program's useful memory requirement in bits.
Repeated values represent separate programs and must all be counted.
There are 4,096 program requests in the complete dataset.

Read the accompanying HTML assignment for the machine description,
design objective, four-step process, and submission requirements.
